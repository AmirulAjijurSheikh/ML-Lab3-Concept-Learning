# ML Lab 3 - Concept Learning

## Aim

To implement and study Concept Learning using the Find-S Algorithm and Candidate-Elimination Algorithm on the given dataset.

## Dataset

enjoy.csv

## Algorithms Used

- Find-S Algorithm
- Candidate-Elimination Algorithm

## Tools Used

- Python
- Jupyter Notebook
- Google Colab
- Pandas
- NumPy
- Seaborn
- Matplotlib

## Description

This laboratory experiment demonstrates concept learning using the Find-S and Candidate-Elimination algorithms. The algorithms are applied to the `enjoy.csv` dataset to determine the specific and general hypothesis boundaries.
